# First Light

Website for **First Light**, an initiative that runs counselling-led programs and workshops to help students build confidence, express themselves and find their path.

Programs:
- **Find Your Voice**: a one-to-one confidence session for children aged 5–12
- **Career Path**: guidance for students choosing subjects, courses and careers (coming soon)

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000

## Structure

```
index.html   page content
style.css    styles
script.js    menu, scroll effects
images/      logo, posters, photos
```
